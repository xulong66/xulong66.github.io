# Long Xu · Academic Homepage

Source for [xulong66.github.io](https://xulong66.github.io/), the English academic homepage of Long Xu.

## Local development

```bash
npm ci
npm run dev
```

## Verification and GitHub Pages build

```bash
npm test
npm run lint
npm run build:pages
```

Pushes to `main` are validated and deployed by `.github/workflows/pages.yml`.
